# CiteVerify-X design brief

User-authored direction with implementation decisions authored to complete the supplied brief.

1. Vibe: "Deep academic obsidian", "precision-calibrated luminescence". References supplied: Bloomberg Terminals and Linear. Geist Sans and Geist Mono, exact requested palette.
2. Journey: "HERO & AUDIT LAUNCHPAD" then "THE FORENSIC WORKBENCH". Choose/upload a paper, see processing, review linked evidence, export.
3. Energy: authored calm entry, brief activity during parsing, concentrated evidence review.
4. Feeling: recognition from manuscript framing; confidence from usable upload; curiosity during timeline; clarity at the selected numerical mismatch. Peak: "I clicked 30% and immediately saw the source's 12%." Lives in the workbench, the longest dwell.
5. Signature: requested bidirectional claim-to-proof pulse, extended into a numeric diff that traces a selected metric between the panes.
6. Range: supplied dense premium analytical interface with cinematic depth at entry.
7. World: two distinct scenes, expressly requested launchpad then /audit/[id].
8. Assets: existing benchmark PDFs, source fixtures, parser coordinates, actual reports. No generated imagery; SVG scientific coordinate field and semantic document content are the world.

Belief: every conclusion should be traceable to source evidence. Primary action: Start audit. Real score, coverage and integrity gaps remain visible. No invented live index count or calibration.

Tell someone: It's the site where you touch a suspect number and see the original evidence across the page.

Feeling curve before score: arrival = composed, coordinate field under restrained headline; launch = agency, tactile PDF target; analysis = anticipation, ordered progress; audit = clarity, selected claim linked to proof; export = resolution, printable report plus actual SHA-256 digest.

Grammar: launch-to-investigation, a custom two-route application grammar specified by the user. Entry has a floating capsule, concise hero and actual upload input; the next route replaces marketing navigation with a command bar and split investigation surface. The close is an exported audit artifact. Bans: artificial pinning, scroll gates, decorative feature galleries, nonfunctional demo panels and inaccessible nested scroll on phones. This differs from pure live surface, whose ban on hero typography conflicts with the requested launchpad. Filmic one-shot, continuous world, chaptered editorial, typographic poster, gallery and rhythmic cutlist add unnecessary scroll or prevent task entry; split stage alone does not cover the upload lifecycle. No artificial scroll span.

Layer contract: background grid at low contrast, ambient cursor light, interactive provenance diagram with shallow parallax, foreground dropzone. Mobile stacks and removes parallax. Headline is static readable text. Reduced motion removes positional entrances, pulse movement and parallax.

| Beat | Device | Purpose |
|---|---|---|
| Arrival | pointer depth | coordinate atmosphere around readable headline |
| Launch | tactile hover/drag | explicit user agency |
| Analysis | sequential reveal | actual pipeline progress |
| Audit peak | linked split view | selected claim and exact passage, numerical diff |
| Export | modal resolve | review score/coverage then download |

Fingerprint gate: registry empty; no previous rows to compare. Build stays short, with no pinned dead space. Framer springs replace standalone scroll engine at user request; reference engine copied to build for provenance only.
